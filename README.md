# 🏠 Real Estate Agency - Modern Web UI

A sleek, responsive, and modern Real Estate Agency landing page built with **HTML 5** and **Tailwind CSS**. This project focuses on high-quality visuals and a clean user interface.
## ✨ Features
* **Fully Responsive Design:** Optimized for mobile, tablet, and desktop screens.
* **Modern Hero Section:** Eye-catching full-screen background with bold typography.
* **Dynamic Image Grids:** Organized property showcases using CSS Grid and Aspect Ratios.
* **Fast Loading:** Optimized with Tailwind CSS for minimal build size.

## 🛠️ Tech Stack
* **Frontend:** HTML5
* **Styling:** Tailwind CSS 4
* **Fonts:** Google Fonts
